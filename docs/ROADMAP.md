# Развитие Read in 60 Seconds

## 1. Надёжная личная доска
- Экспорт и импорт списка.
- Статус «Читаю», даты завершения, заметки.
- Расширенный каталог с проверенными авторами и изданиями.

## 2. Публичный сервис
- Вход и серверное хранение с проверкой владельца каждого списка.
- Синхронизация между устройствами.
- Профили и доски по ссылке; публикация только по явному выбору владельца.
- Удаление аккаунта и выгрузка данных.

## 3. Сообщество
- Подборки по направлениям, копирование подборки в личную доску.
- Жалобы и модерация публичного пользовательского контента.

До реализации второго этапа продукт остаётся локальным браузерным прототипом.
