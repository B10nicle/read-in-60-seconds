# Развитие Read in 60 Seconds

## Реализовано
- Каталог, категории, поиск, отметки и обложки.
- Регистрация и вход по email/паролю; личные книги и прогресс в PostgreSQL.
- Разделение фронтенда и Java 21 API по репозиториям.
- Локальный полный стек в Docker; проверка изоляции пользователей в CI.

## Следующие этапы
- Публичное размещение Java API и PostgreSQL с HTTPS и резервным копированием.
- Подтверждение email, восстановление пароля, удаление аккаунта.
- Импорт гостевой доски, экспорт данных.
- Статус «Читаю», заметки и даты завершения.
- Публичные профили и публикация досок только по выбору владельца.
- Подборки сообщества и модерация публичного контента.

GitHub Pages пока остаётся гостевой демонстрацией; аккаунты работают в полном Docker-стеке.
